# CRM DAJM, mode d'emploi

Motion design (16:9, 1 min 43) qui explique l'utilisation du CRM DAJM dans Notion : les vues, l'anatomie d'une fiche, les types et statuts, la boucle de travail pour la prospection et la fidélisation.

- `index.html` : version animée, lisible dans le navigateur (lecture, pause, curseur, espace pour lancer).
- `video/CRM_DAJM_mode_emploi.mp4` : la vidéo exportée.
- `assets/` : logo DAJM et poses du personnage.
- `music.mp3` : « This Way », Danny Shields (licence Artlist, droits DAJM).

Les contacts affichés sont fictifs.

Pour publier la page : Settings > Pages > Deploy from a branch > `main` / root.
